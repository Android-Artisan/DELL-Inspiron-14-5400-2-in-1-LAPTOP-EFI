# **DELL Inspiron 14 5400 2-in-1 Laptop - OpenCore EFI (macOS Tahoe Stable)**  
OpenCore Hackintosh configuration for the Dell Inspiron 14 5400 2-in-1.
This EFI is **optimized and stable for macOS Tahoe**, boots successfully **up to macOS Tahoe**, and remains **compatible back to macOS Sierra**.

---

## **System Specifications**

| Component | Details |
|----------|---------|
| Model | Dell Inspiron 14 5400 2-in-1 |
| CPU | Intel Core i5-1035G1 (10th-gen Ice Lake) |
| Memory | 16 GB (2 × 8 GB) DDR4 3200 MHz |
| Storage | 2 TB M.2 PCIe NVMe SSD |
| macOS Versions Supported | **macOS Sierra --> macOS Tahoe** |
| Recommended / Stable Version | **macOS Monterey** |
| OpenCore Version | 1.0.6 |
| OS Used During EFI Creation | Windows 11 |
